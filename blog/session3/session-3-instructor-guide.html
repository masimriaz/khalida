Instructor Guide

Session 3 (90 Minutes) – Python Chatbot

A PPT-style, hands-on teaching flow that keeps kids engaged while building Noor step by step.

90 minutes Ages 9–14 Python Basics Build Noor
0–5 min

Welcome + Tech Check

Warm greeting, confirm laptops open, and verify Python runs.

Quick check: Ask kids to run python --version and show the output.
5–10 min

Story Hook: Friendly Python Snake

Python is like a friendly language that helps us talk to computers in simple words. It is popular because it is easy to read, and it can build cool things like games and chatbots.

Tell the story: “Python is a friendly snake who loves clear instructions. When we speak clearly, Python understands and helps us build Noor.”

Mini concept tour:
• Variables are labeled boxes that store information.
• Input is how Noor asks questions and listens.
• If/Else helps Noor make choices.
• Lists are backpacks that hold many items.
• Loops help Noor keep the conversation going.
Ask: What can a chatbot help with? Show final goal Promise: We build Noor today!
10–20 min

Hands‑On 1: Variables + Print

Explain variables as treasure boxes, then run the first code together.

# Variables chatbot_name = "Noor" age = 10 print(chatbot_name) print("My age is", age)
Challenge: Create 3 variables about yourself and print them.
20–30 min

Hands‑On 2: Input

Show how input asks a question and remembers the answer.

user_name = input("What is your name? ") print("Nice to meet you,", user_name)
Mini task: Ask for favorite color and print a friendly reply.
30–45 min

Hands‑On 3: If / Else

Teach decisions with simple feelings and responses.

feeling = input("happy or sad? ") if feeling == "happy": print("Alhamdulillah!") else: print("Allah is with you.")
Game: “If you’re wearing blue, stand up.” Connect it to code.
45–55 min

Hands‑On 4: Lists

Explain lists as backpacks, then add items together.

duas = ["Bismillah", "Alhamdulillah"] print(duas[0]) duas.append("MashaAllah")
Challenge: Add 2 more items to the list.
55–75 min

Build Noor – Chatbot

Combine lists, input, if/else, and loops to build Noor step by step. Explain each concept as we code so kids see how each piece becomes the chatbot.

Instructor tip: After each block, say “Run it!” and celebrate every success out loud.

Step 1: Warm welcome (print)

Concept: print() makes the computer speak.

# Noor says hello! print("As-salamu alaykum! I am Noor.") print("I can answer simple Islamic questions.") print("Type 'bye' to exit.\n")
Fun line: “If Noor can talk, you can too! Say hello back.”

Step 2: Build Noor’s LLM brain (lists)

Concept: Lists store Noor’s “brain” knowledge. It is like a tiny LLM brain with facts it already knows.

# Noor's brain: questions + answers questions = [ "who created us", "how many times do we pray", "what is the quran", "what is ramadan", "what do we say before eating", "who is prophet muhammad" ] answers = [ "Allah (SWT) created us!", "We pray 5 times a day.", "The Quran is Allah's message.", "Ramadan is the blessed month of fasting.", "We say Bismillah before eating.", "Prophet Muhammad ﷺ is our final messenger." ]
Kid prompt: “Let’s add one new Q&A to Noor’s brain together!”

Step 3: Ask the user (input)

Concept: input() lets Noor listen. lower() helps matching.

user_question = input("You: ").lower()
Fun line: “We turn letters to lowercase so Noor doesn’t get confused.”

Step 4: Keep chatting (while loop)

Concept: A loop keeps the conversation going until we say “bye.”

while True: user_question = input("You: ").lower() # Friendly greetings if "salam" in user_question or "assalam" in user_question: print("Noor: Wa alaykumu as-salam!") continue # Gratitude moment if "thank" in user_question: print("Noor: You're welcome! 😊") continue if user_question == "bye": print("Noor: Wa alaykumu as-salam!") break
Kid line: “Noor is a good listener and waits for your next question.”

Step 5: Search Noor’s brain (for loop)

Concept: A loop checks every question to find a match.

# Search in Noor's brain found = False for i in range(len(questions)): if questions[i] in user_question: print("Noor:", answers[i]) found = True break
Kid prompt: “Noor scans like a detective. 🕵️”

Step 6: Friendly fallback (if not found)

Concept: If Noor does not know, it answers kindly.

if not found: print("Noor: I'm still learning. Ask simply!") print()
Joy moment: “Even Noor is a learner—just like us!”

Step 7: Put it all together

Concept: We combine all blocks in one file. Run, test, celebrate.

Mini challenge: Add two new Q&A pairs and create one new greeting rule.
75–85 min

Test + Share

Pair kids to test each other’s chatbot and celebrate wins.

Celebrate correct answers Help fix indentation
85–90 min

Wrap‑Up + Next Steps

Recap skills and give a short homework challenge.

Homework: Add 2 new Q&A pairs to Noor.
Tip: Keep energy high with quick check-ins and celebrate each success.

🐍 AI Superheroes Workshop – Session 3: Coding Our Islamic Chatbot with Python

Time to become real coders! In this session, kids learn Python programming by bringing their Islamic chatbot designs to life—one line of code at a time!

Ages 9–14 90 minutes Beginner Python Islamic Values
📋 Session Overview

What We'll Learn Today

Welcome back, AI Superheroes! In Sessions 1 and 2, we learned what AI is and designed our Islamic chatbot "Noor." Today, we're going to learn how to actually build it using Python—a friendly programming language that talks to computers!

🎯 Learning Goals

  • Understand Python – What it is and why it's perfect for chatbots
  • Learn basic coding – Variables, input/output, if/else, and lists
  • Build a real chatbot – Create a working Islamic chatbot in Python
  • Test and improve – Run our chatbot and add more features
  • Think like a coder – Break problems into small steps

📖 The Story of Python the Friendly Snake 🐍

Once upon a time, a man named Guido wanted to create a programming language that was easy to read and fun to use—like having a friendly conversation with a computer!

He named it "Python" (after a funny TV show, not the snake!). Python became so loved that today, millions of people use it to build amazing things: chatbots, games, websites, and even AI!

Why do we love Python?

  • ✅ It's easy to read (almost like English!)
  • ✅ It's powerful (can build chatbots, games, AI)
  • ✅ It's friendly (great for beginners)
  • ✅ It's free (anyone can use it)

🏗️ Part 1

Variables & Print: Storing & Showing Information

📖

The Treasure Box Story

Imagine you have a treasure box with a label on it. You can put something inside (like your favorite toy's name) and later open the box to see what's inside!

In Python, we call these boxes "variables"—they store information for us!

🎓 Concept: Variables

A variable is like a labeled box that holds information.

# This is how we create a variable (treasure box) chatbot_name = "Noor" # Put "Noor" in the box labeled "chatbot_name" age = 10 # Put the number 10 in the box labeled "age" is_kind = True # Put True (yes) in the box labeled "is_kind"
Teacher Tip

Use physical boxes or index cards to demonstrate variables! Write labels and put toy items inside to show how variables work.

🎓 Concept: Print (Showing Messages)

To show a message on screen, we use print()—it's like asking the computer to speak!

# Tell the computer to say hello! print("As-salamu alaykum!") print("My name is", chatbot_name) # Show the treasure from our box!
Kids Activity #1: Create Your Own Variables

Task: Everyone creates 3 variables about themselves:

  • my_name = your name
  • my_age = your age
  • favorite_subject = what you love to learn

Then: Use print() to show these on screen!

🎉

Checkpoint #1

Amazing! You just learned how computers remember information! Give yourself a high-five! 🙌

🎤 Part 2

Input & If/Else: Asking Questions & Making Decisions

📖

The Smart Robot Story

Imagine you meet a friendly robot. The robot asks: "What is your name?" You tell it, and the robot remembers!

Then the robot says: "If your name starts with 'A', I'll call you Amazing!"

This is exactly what input() and if/else do in Python!

🎓 Concept: Input (Asking Questions)

input() lets your program ask the user a question and wait for an answer!

# Ask the user their name and store it in a variable user_name = input("What is your name? ") print("Nice to meet you,", user_name, "!")

🎓 Concept: If/Else (Making Decisions)

Sometimes we want our program to do different things based on the answer. That's where if/else comes in!

# Ask a question feeling = input("How are you feeling? (happy/sad) ") # Make a decision based on the answer if feeling == "happy": print("Alhamdulillah! I'm happy too! 😊") elif feeling == "sad": print("Don't worry! Allah is always with you. 🤲") else: print("I hope you have a blessed day!")
Teacher Tip

Act out if/else with kids! Say: "If you're wearing blue, stand up. Else, sit down." This shows decision-making in action!

Kids Activity #2: Build a Greeting Bot

Task: Create a simple program that:

  1. Asks: "What time is it? (morning/afternoon/evening)"
  2. If morning → says "Good morning! Start your day with Bismillah!"
  3. If afternoon → says "Good afternoon! Hope your day is blessed!"
  4. If evening → says "Good evening! Don't forget your evening dua!"

🎉 Checkpoint #2

Wow! Your programs can now talk AND think! You're becoming real coders! 💪

📚 Part 3

Lists: Storing Many Things at Once

📖 The Backpack Story

Imagine your school backpack. Instead of carrying one pencil, you carry a list of items: pencil, eraser, notebook, snack!

In Python, a list is like a backpack—it holds many items in one place!

🎓 Concept: Lists

A list stores multiple items in order. We use square brackets [ ] to create them.

# Create a list of duas (prayers) duas = ["Bismillah", "Alhamdulillah", "SubhanAllah"] # Access items by their position (counting starts at 0!) print(duas[0]) # Shows "Bismillah" (first item) print(duas[1]) # Shows "Alhamdulillah" (second item) # Add a new item to the list duas.append("MashaAllah") print(duas) # Shows all 4 duas!
Teacher Tip

Use flashcards arranged in a row to demonstrate lists! Number them 0, 1, 2, 3 to show how Python counts from zero.

🎓 Why Lists Are Perfect for Chatbots

Our chatbot needs to remember MANY questions and answers! Lists help us organize them like flashcards.

# Store questions and answers together! questions = ["Who created us?", "What do we say before eating?"] answers = ["Allah created us", "We say Bismillah"] # When someone asks question 0, give answer 0! print("Q:", questions[0]) print("A:", answers[0])
Kids Activity #3: Create Your Q&A List

Task: Create two lists:

  • my_questions = 3 Islamic questions kids ask
  • my_answers = 3 kind, simple answers

Example:

  • Q: "How many times do we pray?" → A: "We pray 5 times a day!"

🎉 Checkpoint #3

You're ready! Now you know ALL the Python basics to build a chatbot! Let's do this! 🚀

🤖 Build Time!

Building "Noor" - Our Islamic Chatbot

Time to put everything together! We'll build our chatbot step by step. Follow along and type the code with us!

Step 1: Welcome Message

First, let's make our chatbot introduce itself!

# Step 1: Welcome the user print("╔════════════════════════════════╗") print("║ As-salamu alaykum! 🌙 ║") print("║ I am Noor, your kind ║") print("║ Islamic helper chatbot! ║") print("╚════════════════════════════════╝") print()
Teacher Tip

Ask a volunteer to read the welcome message out loud! Make it fun and engaging. Encourage kids to customize their chatbot's name.

Step 2: Get the User's Name

Let's ask who we're talking to!

# Step 2: Get user's name user_name = input("What is your name? ") print("Nice to meet you,", user_name, "! 😊") print()

Step 3: Store Q&A Pairs

Now we create our knowledge base—the questions Noor knows about!

# Step 3: Create our Q&A database using lists questions = [ "who created us", "how many times do we pray", "what do we say before eating", "what is the quran", "how should we treat others" ] answers = [ "Allah (SWT) created us and everything in the universe! ☝️", "We pray 5 times a day: Fajr, Dhuhr, Asr, Maghrib, and Isha! 🕌", "We say 'Bismillah' (In the name of Allah) before eating! 🍎", "The Quran is Allah's beautiful message to guide us in life! 📖", "We should treat everyone with kindness, respect, and love! ❤️" ]
Volunteer Moment!

Ask 2-3 kids to suggest more questions and answers! Add them to the lists together as a group.

Step 4: The Chatbot Loop

This is the brain! Our chatbot will keep asking what the user wants to know.

# Step 4: Main chatbot conversation loop print("You can ask me anything about Islam!") print("Type 'bye' when you want to leave.\n") while True: # Get user's question user_question = input(user_name + ": ").lower() # Convert to lowercase # Check if user wants to exit if user_question == "bye": print("Noor: Wa alaykumu as-salam! May Allah bless you! 🤲") break # Exit the loop # Search for the answer found_answer = False for i in range(len(questions)): if questions[i] in user_question: print("Noor:", answers[i]) found_answer = True break # If we don't know the answer if not found_answer: print("Noor: I'm still learning! Can you ask in a simpler way? 🤔") print() # Add spacing for readability
Teacher Tip

Explain the loop: "This is like a conversation that keeps going until we say 'bye'—just like talking with a friend!" Walk through the logic slowly, one line at a time.

🎯 The Complete Chatbot Code

Here's everything put together! This is the full working chatbot:

# ================================================ # NOOR - My Kind Islamic Chatbot # Created by: [Student's Name] # Date: February 7, 2026 # ================================================ # Welcome message print("╔════════════════════════════════╗") print("║ As-salamu alaykum! 🌙 ║") print("║ I am Noor, your kind ║") print("║ Islamic helper chatbot! ║") print("╚════════════════════════════════╝") print() # Get user's name user_name = input("What is your name? ") print("Nice to meet you,", user_name, "! 😊\n") # Knowledge base: Questions and Answers questions = [ "who created us", "how many times do we pray", "what do we say before eating", "what is the quran", "how should we treat others", "what is ramadan", "who is prophet muhammad" ] answers = [ "Allah (SWT) created us and everything in the universe! ☝️", "We pray 5 times a day: Fajr, Dhuhr, Asr, Maghrib, and Isha! 🕌", "We say 'Bismillah' (In the name of Allah) before eating! 🍎", "The Quran is Allah's beautiful message to guide us in life! 📖", "We should treat everyone with kindness, respect, and love! ❤️", "Ramadan is the blessed month when we fast from dawn to sunset! 🌙", "Prophet Muhammad ﷺ is the last messenger of Allah and our role model! ✨" ] # Main conversation loop print("You can ask me anything about Islam!") print("Type 'bye' when you want to leave.\n") while True: # Get user's question user_question = input(user_name + ": ").lower() # Check if user wants to exit if user_question == "bye": print("Noor: Wa alaykumu as-salam! May Allah bless you! 🤲") break # Search for the answer in our knowledge base found_answer = False for i in range(len(questions)): if questions[i] in user_question: print("Noor:", answers[i]) found_answer = True break # If we don't know the answer if not found_answer: print("Noor: I'm still learning! Can you ask in a simpler way? 🤔") print() print("Thank you for chatting with me, " + user_name + "! 💚")

🎉 You Did It!

YOU JUST BUILT A REAL CHATBOT! Time to test it! 🚀

🧪 Testing Time

Running & Testing Our Chatbot

How to Run Your Chatbot

  1. Save your code as noor_chatbot.py
  2. Open your terminal or command prompt
  3. Type: python noor_chatbot.py
  4. Press Enter and watch the magic! ✨

Test These Questions

Try Asking Noor:
  • "Who created us?"
  • "How many times do we pray?"
  • "What is Ramadan?"
  • "Tell me about Prophet Muhammad"
  • "What happens when I ask something Noor doesn't know?"
Teacher Tip

Group Activity: Have kids pair up and test each other's chatbots! One asks questions while the other demonstrates. Celebrate when the chatbot responds correctly!

🐛 What If Something Goes Wrong?

Don't worry! Every coder faces errors. Here's how to fix common ones:

Common Fixes
  • IndentationError: Check your spacing! Python uses spaces to group code.
  • NameError: Did you spell your variable name correctly?
  • SyntaxError: Did you forget a quote mark (") or colon (:)?
  • Chatbot doesn't respond: Make sure your question matches words in the questions list!

🛡️ Safety First

Chatbot Best Practices - Being Responsible Coders

✅ What Our Chatbot SHOULD Do

  • ✅ Use kind, respectful language
  • ✅ Give accurate Islamic information (verified by adults)
  • ✅ Say "I don't know" instead of guessing
  • ✅ Encourage learning and curiosity
  • ✅ Respect all people regardless of background

❌ What Our Chatbot Should NOT Do

  • ❌ Share personal information (addresses, phone numbers)
  • ❌ Give medical or legal advice
  • ❌ Make fun of anyone or any belief
  • ❌ Discuss adult topics
  • ❌ Pretend to be a real scholar (we're learning!)

🛡️ The Safety Shield

Remember: Our chatbot is a learning tool, not a replacement for parents, teachers, or scholars!

If someone asks something inappropriate, our chatbot should say:

"I'm a learning chatbot for kids! Please ask a parent, teacher, or trusted adult about this question. 🤲"

Adding a Safety Check

# List of topics we shouldn't discuss unsafe_topics = ["password", "address", "phone", "credit card"] # Check if question contains unsafe words for unsafe_word in unsafe_topics: if unsafe_word in user_question: print("Noor: That's private information! Never share it online. 🛡️") continue # Skip to next question

💻 VS Code & Python Setup Guide

Learn to code in Python with VS Code - Step by Step!

🚀What Are We Installing?

We're setting up two important tools for Python coding:

  • Python: The programming language where you'll write your code
  • VS Code: A super cool text editor where you'll write and run your code

✨ Good News! This setup takes about 10-15 minutes and is completely free!

🐍Step 1: Install Python

1

Go to Python's Official Website

Open your web browser and go to: python.org

Or click here: python.org/downloads

2

Click the Downloads Button

You'll see a big yellow button that says "Download Python 3.x.x" (the version might be different)

Click it to download Python for your computer.

3

Run the Installer

Find the downloaded file (usually in your Downloads folder) and double-click it to open it.

4

⚠️ IMPORTANT: Check the "Add Python to PATH" Box

When the installer opens, you'll see a checkbox that says "Add Python 3.x to PATH"

✅ Make sure to CHECK this box before clicking Install!

5

Click "Install Now"

Let the installer do its magic! Wait for it to finish (you might see a progress bar).

🎉 Great! Python is now installed on your computer!

✔️Step 2: Verify Python is Installed

1

Open Command Prompt (Windows) or Terminal (Mac/Linux)

On Windows: Press the Windows key, type "Command Prompt" and press Enter

On Mac: Press Cmd + Space, type "Terminal" and press Enter

2

Type This Command

python --version

Then press Enter

3

Check the Result

You should see something like: Python 3.11.5 (the exact version might be different)

If you see a version number, Python is installed correctly! ✨

💡 Tip: If you get an error, try typing python3 --version instead

📥Step 3: Download VS Code

1

Visit the VS Code Website

Go to: code.visualstudio.com

Or click here: code.visualstudio.com

2

Click the Download Button

The big blue "Download" button will automatically suggest the right version for your computer.

Click it to download VS Code.

3

Run the Installer

Find the downloaded file in your Downloads folder and double-click it.

4

Follow the Installation Steps

The installer will ask you questions. Just click "Next" and "Install" for all the default options.

🎊 Awesome! VS Code is now installed!

🧩Step 4: Install the Python Extension

1

Open VS Code

Double-click the VS Code icon or find it in your Start menu (Windows) or Applications (Mac).

2

Go to Extensions

On the left side, you'll see a square icon that looks like this: ■ ■

Click it to open Extensions (or press Ctrl+Shift+X)

3

Search for Python

Type "Python" in the search box at the top.

The first result should be "Python" by Microsoft (with the blue icon)

4

Click Install

Click the blue "Install" button and wait for it to finish.

✅ Perfect! You now have the Python extension installed in VS Code!

📝Step 5: Write Your First Python Program

1

Create a New Folder

On your computer, create a new folder called "PythonProjects" or "MyCode"

2

Open the Folder in VS Code

Open VS Code and click File → Open Folder

Select the folder you just created and click "Select Folder"

3

Create a New Python File

Right-click in the empty folder area on the left and choose "New File"

Name it: hello.py

4

Write Your First Program

Type this code:

print("Hello, Python World! 🎉")
5

Save Your File

Press Ctrl+S (Windows) or Cmd+S (Mac) to save

6

Run Your Program

Right-click in the code editor and click "Run Python File in Terminal"

Or press the ▶️ button in the top-right corner

🌟 Congratulations! You've just written and run your first Python program! You should see:

Hello, Python World! 🎉

🆘Troubleshooting Help

Problem: "Python is not recognized" error

Solution: You might need to add Python to PATH manually. Restart your computer first. If that doesn't work, ask an adult for help reinstalling Python and make sure to check "Add Python to PATH".

Problem: VS Code doesn't recognize Python files

Solution: Make sure you installed the Python extension in Step 4. Also try restarting VS Code.

Problem: "No module named..." error

Solution: This means you're trying to use a library that isn't installed. We'll show you how to install libraries in later lessons!

Problem: The run button doesn't work

Solution: Try opening the terminal at the bottom of VS Code and typing: python hello.py (replace with your filename)

💡Pro Tips for Success

  • File Names Matter: Always use lowercase letters and no spaces in your Python filenames (use underscore instead: my_code.py)
  • Keep Organized: Create a folder for each project to keep your code neat
  • Read Error Messages: When something goes wrong, read the error message carefully - it usually tells you what's wrong!
  • Use Comments: Write comments in your code using # to explain what your code does
  • Practice Regularly: Code a little every day to improve faster!
